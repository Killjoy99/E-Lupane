Audit and improve the LMS for accessibility.

Check:

- Keyboard navigation
- Focus management
- Screen readers
- Semantic HTML
- Form labels
- Error messages
- Color contrast
- Font scaling
- Captions
- Transcripts
- Alternative text
- Accessible tables
- Accessible dialogs
- Accessible video controls

Follow an appropriate WCAG target for the project.

Do not solve accessibility issues by hiding functionality.

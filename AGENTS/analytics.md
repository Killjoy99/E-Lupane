Implement analytics and reporting.

Student analytics:

- Course progress
- Time spent
- Lessons completed
- Quiz performance
- Assignment performance
- Exam performance
- Attendance
- Completion rate

Instructor analytics:

- Enrollment
- Student performance
- Completion
- Average grade
- Engagement

Administrator analytics:

- Active users
- Enrollments
- Completion rates
- Dropout/inactivity
- Course performance
- Instructor activity
- Revenue

Create report exports:

- PDF
- CSV
- Excel

Do not calculate large reports inefficiently on every page request. Design appropriate aggregation or background processing.

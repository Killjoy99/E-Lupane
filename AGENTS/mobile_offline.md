Implement mobile-friendly learning functionality.

Students should be able to:

- Login
- Browse courses
- View lessons
- Watch videos
- Take quizzes
- Submit assignments
- View grades
- Receive notifications
- View certificates

Design offline support for:

- Downloaded documents
- Downloaded lessons
- Offline progress
- Synchronization

Offline synchronization must handle conflicts safely.

Do not allow offline clients to bypass server-side authorization.
